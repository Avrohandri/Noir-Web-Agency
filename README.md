# 🌑 Noir Web Agency

Website resmi dan landing page layanan **Noir Web Agency** — Jasa pembuatan website profesional, landing page konversi tinggi, toko online, dan aplikasi web kustom dengan desain modern dan performa tinggi.

---

## 🚀 Fitur Website
- **Estetika Noir Modern**: Desain bernuansa gelap (*sleek dark mode*) dengan ambient lighting & tipografi futuristik.
- **Responsif Penuh**: Tampilan optimal di smartphone, tablet, laptop, dan layar monitor desktop.
- **Section Lengkap**:
  - Hero Section & Metrik Performa
  - Daftar Layanan (Company Profile, Landing Page, E-Commerce, Web App)
  - Portofolio / Showcase Preview
  - Paket Harga Transparan
  - Form Pemesanan / Konsultasi langsung terhubung ke WhatsApp

---

## 📁 Struktur Direktori
```text
Noir-Web-Agency/
├── index.html        # Struktur halaman utama website
├── style.css         # Styling dark theme & responsivitas
```

Cukup buka file `index.html` langsung di browser Anda (klik ganda file `index.html`), atau gunakan ekstensi seperti **Live Server** di VS Code / Antigravity IDE.

## 👥 Cara Menambahkan Teman Sebagai Kolaborator (Bisa Push & Pull)

Agar teman Anda bisa melakukan `git push` dan `git pull` langsung ke repository [Avrohandri/Noir-Web-Agency](https://github.com/Avrohandri/Noir-Web-Agency), ikuti langkah berikut:

1. Buka repository Anda di GitHub: [https://github.com/Avrohandri/Noir-Web-Agency](https://github.com/Avrohandri/Noir-Web-Agency)
2. Klik tab **Settings** (ikon gerigi di kanan atas menu repo).
3. Di panel sebelah kiri, klik menu **Collaborators** (di bawah bagian *Access*).
4. Klik tombol hijau **Add people**.
5. Masukkan **Username GitHub** atau **Email** teman Anda.
6. Klik **Add [nama user] to this repository**.
7. Teman Anda akan menerima notifikasi email atau undangan di akun GitHub mereka. Setelah teman Anda mengklik **Accept Invitation**, mereka sudah bisa melakukan `git push` dan `git pull` secara langsung!

---

## 📤 Cara Mengupload File Ini ke GitHub

Jalankan perintah berikut di terminal komputer Anda pada folder ini:

```bash
# 1. Inisialisasi git (jika belum ada)
git init

# 2. Tambahkan semua file
git add .

# 3. Buat commit pertama
git commit -m "feat: initial release Noir Web Agency landing page"

# 4. Arahkan branch ke main
git branch -M main

# 5. Hubungkan ke repository GitHub Anda
git remote add origin https://github.com/Avrohandri/Noir-Web-Agency.git

# 6. Push file ke GitHub
git push -u origin main
```
